# Half-Day Leave Policy

Half-day leave lets you take either the first half or the second half of
a working day off, deducting 0.5 days from the relevant leave balance.

## Rules

1. Half-day leave is available for all three leave types: casual, sick,
   and earned.
2. A half-day request covers exactly one calendar day — the start date
   and end date must be the same. Multi-day half-day requests are not
   supported; file separate requests per day if needed.
3. When filing, you must specify which half you are taking: FIRST_HALF
   (morning, until 1:30 PM) or SECOND_HALF (afternoon, from 1:30 PM).
   A half-day request without this specification is invalid.
4. The half-day specification is only valid on half-day requests — a
   full-day request must not carry one.
5. A half-day request is deducted as 0.5 days from the balance of the
   chosen leave type upon approval.
6. Overlap rules apply as with any leave: a half-day request cannot be
   filed on a date already covered by another pending or approved
   request, including another half-day.
7. Approval flow is identical to full-day leave: manager approval is
   required, and planned half-days should be requested 2 working days
   in advance where possible.
